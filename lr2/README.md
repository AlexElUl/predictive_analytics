# Прогнозирование концентрации выходного продукта печи обжига

Проект предсказывает концентрацию выходного продукта печи обжига по показаниям датчиков телеметрии, заменяя нерегулярные лабораторные замеры на непрерывный прогноз в реальном времени.

## Структура проекта

```
├── data/
│   ├── data_train.csv        # Телеметрия для обучения
│   ├── target_train.csv      # Лабораторные замеры для обучения
│   ├── data_test_small.csv   # Телеметрия для тестирования
│   └── target_test_small.csv # Лабораторные замеры для тестирования
├── sol.ipynb                 # Основной ноутбук
├── req.txt                   # Зависимости
└── README.md
```

## Установка

```bash
# Создать виртуальное окружение
python3 -m venv myenv
source myenv/bin/activate

# Установить зависимости
pip install -r req.txt
```
# Также требуется утаноить датасеты в папку "data/"

## Запуск

Открыть и последовательно запустить все ячейки `sol.ipynb`. Ячейки выполняются строго по порядку — каждая зависит от предыдущей.

## Структура ноутбука

### 2.1 Разведочный анализ (EDA)
- Визуальный анализ телеметрии: тренды, сезонность, выбросы, пропуски
- Исследование целевой переменной: распределение, частота, задержки
- Синхронизация телеметрии и лабораторных замеров с учётом задержки 12 минут
- Корреляционный анализ с учётом лагов

### 2.2 Инжиниринг признаков
- Лаговые признаки для ключевых датчиков
- Скользящие статистики (mean, std, min, max) с окнами 10, 60, 120 минут
- Производные и темпы роста

### 2.3 Обучение и оценка моделей
- Ridge (baseline)
- ExtraTreesRegressor
- CatBoostRegressor

## Интерпретация результатов

### Метрики
| Метрика | Описание | Лучшее значение |
|---|---|---|
| MAE | Средняя абсолютная ошибка в единицах концентрации | Меньше |
| RMSE | Чувствителен к крупным ошибкам | Меньше |
| MAPE | Ошибка в процентах | Меньше |
| WAPE | Взвешенная ошибка, устойчива к нулям | Меньше |
| Directional Accuracy | Доля правильно угаданных направлений изменения | Больше (макс. 1.0) |

### Результаты моделей
| Модель | MAE | RMSE | MAPE | WAPE |
|---|---|---|---|---|
| Ridge | 0.063 | 0.076 | 0.362 | 0.305 |
| ExtraTrees | 0.059 | 0.072 | 0.329 | 0.286 |
| **CatBoost** | **0.056** | **0.071** | **0.286** | **0.274** |

CatBoost показал лучший результат по всем метрикам.

### Ключевые признаки
Наиболее важные для прогноза — `telemetry_0` и его скользящие статистики за 60 минут. Рост `telemetry_0` повышает прогноз концентрации, рост `telemetry_9` и `telemetry_10` — снижает.

### Важно
Directional Accuracy ~32% у всех моделей говорит о том что модели хорошо предсказывают значение концентрации, но не направление изменений — это следствие нерегулярности лабораторных замеров.
